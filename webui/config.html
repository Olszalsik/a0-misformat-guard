Layer 1 — Primary cascade

Sits at call_chat_model_turn/end. When the chat model emits a response the framework's JSON tool extractor cannot parse, the cheap utility model is asked to repair it. The repaired text replaces the broken one before the monologue loop ever sees it. Catches the rare misformat that slipped past the primary cascade (e.g. utility model returned syntactically valid but semantically broken JSON). Re-invokes process_tools with the repaired text.

Layer 2 — Hardened parser

Handles unescaped quotes inside long string values. When ON, the hardened parser runs only when the core parser already failed (zero per-turn cost on the happy path).

Layer 3 — Prompt steering

Steers the LLM to use safe quote forms and reduces misformat rate at the source. Appends a one-liner explaining that unescaped quotes are the dominant cause, so the LLM self-corrects.

Layer 4 — Cascade configuration

The cascade uses the cheap utility model (not the chat model) to repair broken responses. The chat model is never called for repairs.

Layer 4 — Upstream circuit-breaker coordination (v0.4.1)

Agent Zero's framework has its own cost circuit breaker that stops the agent after 2 consecutive fw.msg_misformat.md warnings. v0.4.1 hooks the same extension point to keep that counter from triggering on cascade-handled misformats. The _10_misformat_consume_warning hook runs before _90_stop_unusable_response_loop and rewrites loop_data.params_persistent["_unusable_response_failures"] so the framework never sees a streak longer than 1. Disable this only if you want to measure the raw misformat rate.

Layer 5 — Tool-repeat guard (v0.5.0)

Breaks the "reasoning death-loop" the framework's own breakers miss: the agent re-emits the same tool call with the same args and gets an error each time (e.g. a code_editor patch with a stale old_text). The misformat/repeat breakers miss it because the call is well-formed (no misformat warning) and each error is appended to history (no byte-identical repeat). This guard tracks a per-context streak and warns, then hard-stops the turn. When OFF, the hook is a no-op and the agent may loop on a failing call indefinitely. When ON, the thresholds below take effect.
Consecutive identical fails before the soft warning. 0 = never warn.
Consecutive identical fails before the turn is hard-stopped. 0 = never stop.
When ON, trivial whitespace variants of the same args collapse to one streak. Off by default (strict) — the byte-identical death-loop needs no normalization, and over-normalizing risks false positives. Advanced keys (tool_repeat_error_patterns, tool_repeat_ignored_tools) are not UI-persisted — edit default_config.yaml or the framework plugin config directly.
